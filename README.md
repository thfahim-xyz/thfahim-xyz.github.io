## Tech Stack

- **Jekyll** — Static site generator
- **Liquid** — Templating
- **HTML** — Page structure
- **CSS** — Styling and responsive design
- **JavaScript** — Client-side functionality
- **Markdown** — Content and posts
- **GitHub Pages** — Hosting and deployment

The site is designed to remain lightweight, fast, responsive, and easy to maintain.

## Deployment

The site is deployed as a static website through GitHub Pages. Changes pushed to the repository are used to update the live site.
